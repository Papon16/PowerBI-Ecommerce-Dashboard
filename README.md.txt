# 📊 Ecommerce Sales Dashboard (Power BI)

## 📌 Project Overview

This project is an interactive Ecommerce Sales Dashboard developed using Microsoft Power BI. The dashboard provides insights into sales performance, profit analysis, product-wise sales, category-wise profit, regional performance, and discount analysis.

---

## 🚀 Features

- 📈 Total Profit KPI
- 💰 Product-wise Sales Analysis
- 📊 Category-wise Profit Analysis
- 🌍 Region-wise Profit Trend
- 🎯 Discount Percentage Analysis
- 📋 Interactive Filters and Tables

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

---

## 📂 Dataset

**File:** `ecommerce_clean_dataset_500_rows.csv`

The dataset contains ecommerce sales information including:

- Product Name
- Category
- Region
- Sales Amount
- Profit
- Quantity
- Discount Percentage
